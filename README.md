# Teeth Talk Dental

Premium static website for **Teeth Talk Dental** — Root Canal Specialist & Smile Design Clinic, Dr. Ujjwal Chandra Jha (MDS Gold Medalist), Sector 46, Noida.

Built with React 19, Vite, TypeScript, Tailwind CSS, Framer Motion, Swiper, and React Router. Designed in the **Emerald Heritage** luxury system (cream paper, deep emerald, brass accents).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Push this repo to GitHub
2. Import the project in [Vercel](https://vercel.com)
3. Framework preset: **Vite** (defaults are fine)
4. Deploy — `vercel.json` handles SPA routing

## Project notes

- Clinic content lives in `src/data/clinic.ts` (sourced from `data/business.json`)
- Optimized local media in `public/images` and `public/videos`
- Consultation & assessment forms open WhatsApp with a prefilled message to `+91 88267 70113`
